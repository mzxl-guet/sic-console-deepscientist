# 采样定理与混叠现象的量化验证

**实验报告** · 2026-10-19 · 桂林电子科技大学 信息与通信学院

---

## 一、实验目的

用数值实验定量验证采样定理的两条结论：

1. 当采样率满足 `fs > 2·f_max` 时，采样后仍能唯一还原原信号；
2. 当 `fs ≤ 2·f_max` 时必然发生混叠，混叠频率服从折叠公式
   `f_alias = |f0 − k·fs|`，其中 `k = round(f0/fs)`，结果落在 `[0, fs/2]`。

## 二、实验设定

| 项目 | 取值 |
|---|---|
| 信号 | `x(t) = sin(2π·f0·t + φ)` |
| 信号频率 | `f0 = 3000 Hz` |
| 初相 | `φ = π/4` |
| 采样时长 | `T = 0.2 s` |
| 采样率 | `fs = 8000 / 4000 / 3000 / 2000 / 1200 Hz` |
| 采样点数 | `N = fs·T`（1600 / 800 / 600 / 400 / 240） |
| 频率分辨率 | `df = fs/N = 1/T = 5 Hz`（五组完全相同） |
| 窗函数 | 矩形窗（不加以便观察泄漏与混叠） |

**关于初相 φ = π/4**：若取 φ = 0，则 `fs = f0 = 3000 Hz` 时每个采样点都落在正弦过零点上，
采样序列恒等于 0，混叠到直流这一现象反而观察不到。加一个非零初相后，该组采样序列
恒等于 `sin(φ) = 0.707`，直流分量才显现出来。

## 三、实验结果

| fs (Hz) | 奈奎斯特频率 (Hz) | 满足采样定理 | 理论混叠 (Hz) | 实测峰值 (Hz) | 绝对误差 (Hz) |
|---:|---:|:---:|---:|---:|---:|
| 8000 | 4000 | 是 | 3000 | 3000 | 0 |
| 4000 | 2000 | 否 | 1000 | 1000 | 0 |
| 3000 | 1500 | 否 | 0 | 0 | 0 |
| 2000 | 1000 | 否 | 1000 | 1000 | 0 |
| 1200 | 600 | 否 | 600 | 600 | 0 |

- 五组实测峰值与理论混叠频率**完全一致**，绝对误差均为 0 Hz。
- 误差为 0 的原因是：所有频率都是 5 Hz 的整数倍，恰好落在 FFT 频点上，
  不存在栅栏效应引起的偏差。若把 f0 改为 3000.3 Hz，误差会表现为约 0.3 Hz 的栅栏偏差。

## 四、图表说明

**图 1 `fig1_time_domain.png`｜时域采样点**

- fs = 8000 Hz：采样点完整贴合连续曲线，肉眼可判断能还原；
- fs = 4000 / 2000 / 1200 Hz：采样点稀疏地"跨过"了波峰波谷，连接起来会得到频率完全不同的假波形；
- fs = 3000 Hz：所有采样点停在同一高度 0.707，采样序列变成一条直流。

**图 2 `fig2_spectrum.png`｜幅度谱（dB）**

- 每组只有一根主谱线，说明单音信号采样后仍是单音——只是频率被"折叠"了；
- 红色虚线为真实频率 3000 Hz，绿色点线为理论混叠频率，实测峰值始终落在绿色线上；
- fs = 3000 Hz 那组的谱线贴在 0 Hz，即直流。

**图 3 `fig3_alias_summary.png`｜汇总对照**

- 左图：奈奎斯特频率 `fs/2` 随 fs 线性上升，只有 fs = 8000 时高于 3000 Hz；
- 右图：混叠频率随采样率**非单调**变化，2000 Hz 与 4000 Hz 两个采样率混叠到同一个 1000 Hz。
  这正是"看频谱无法反推真实频率"的直接证据。

## 五、两个边界情况

**1. `fs = f0 = 3000 Hz`（混叠到直流）**

每个采样周期恰好采一个点，且相位恒定，序列为常数。频域上只剩 0 Hz 分量。
这是最容易误判的情形：如果只看频谱，会误以为信号是直流而不是 3 kHz 正弦。

**2. `fs = 1200 Hz`（混叠落在奈奎斯特频率上）**

`f0/fs = 2.5`，`k` 取 2 或 3 都得到 `|3000 − 2400| = |3000 − 3600| = 600 Hz`，
恰好等于 `fs/2`。此时正弦与余弦不可区分（相位信息丢失），属于临界状态。

## 六、结论

1. 采样定理的边界是**严格**的：`fs > 2·f0` 时谱线位置正确；`fs ≤ 2·f0` 时谱线一定被折叠，
   且折叠位置可由 `|f0 − k·fs|` 精确预测，本实验五组全部命中，误差 0 Hz。
2. 混叠不是"误差"，而是**信息丢失**：4000 Hz 与 2000 Hz 两种采样率给出完全相同的
   1000 Hz 谱线，仅凭采样后的数据无法区分原始频率是 3000 Hz 还是别的。
3. 工程含义：抗混叠滤波器必须放在采样器**之前**，且截止频率低于 `fs/2`；
   采样后再滤波无法恢复已经混叠的信息。
4. 实践中 `fs` 应留有余量（常用 2.5～5 倍 `f_max`），因为真实信号不是单音，
   且滤波器滚降需要过渡带。
